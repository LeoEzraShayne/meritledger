使用指南

快速上手，开始您的修身之旅

🚀 快速开始

功过格是一款简单易用的修身应用。以下是快速上手指南：

  1. 下载并安装应用
    从应用市场下载并安装功过格应用。
  2. 首次启动
    打开应用，您会看到启动页面和"命自我立，福自己求"的格言。
  3. 开始记录
    点击首页的"记一功"或"记一过"按钮，开始记录您的善行或过失。

📝 如何记录功过

记录功（善行）

  1. 选择类型
    点击"记一功"按钮，进入记录页面。
  2. 选择分值
    根据善行的大小选择合适的分值：
    • 一功：拾金不昧、善语待人
    • 十功：施财救急、谏止恶行
    • 三十功：救人危难、成人之美
    • 百功：救人一命、活命无数
  3. 添加详情
    可选择性添加备注说明、上传图片或录制语音，让记录更完整。
  4. 保存记录
    点击保存按钮，记录成功后会显示"善已存"的提示。

记录过（过失）

  1. 选择类型
    点击"记一过"按钮，进入记录页面。
  2. 选择分值
    根据过失的大小选择合适的分值：
    • 一过：轻慢之失、言行不谨
    • 十过：见义不为、恶语伤人
    • 三十过：损人利己、见死不救
    • 百过：害人性命、大恶不赦
  3. 添加详情
    记录具体情况，帮助自己认识过失，以便改过。
  4. 保存记录
    点击保存按钮，记录成功后会显示"过已存"的提示。
💡 提示： 记录过失是为了改过，培养自省习惯。正如《了凡四训》所说："过由心造，亦由心改"。

📊 查看统计

今日统计

在首页可以看到今日累计的功和过，实时更新。

本周趋势

在首页的"本周趋势"区域，可以看到本周的功过趋势图表，了解一周的修行状态。

历史查看

  1. 进入日历
    点击首页的"历史日历"按钮，进入日历页面。
  2. 选择日期
    在日历上选择有记录的日期（会有标记）。
  3. 查看详情
    点击日期，可以查看该日的所有记录和累计功过。

功德碑

点击首页的"功德碑"按钮，可以查看自使用以来的总功和总过，见证长期的修行积累。

📈 命运刻度

命运刻度是根据您的功过记录计算出的综合指数，反映您的修行状态。

  1. 查看当前等级
    在首页的"命运刻度"区域，可以看到当前的等级（暗淡、微光、明光、昼明、辉耀）。
  2. 查看趋势
    可以看到近30日的趋势，了解自己的进步情况。
  3. 提升等级
    通过持续记录善行，减少过失，可以提升命运刻度等级。
💡 提示： 命运刻度是根据功过比例和累计值自动计算的，持续修行可以改变命运。

⚙️ 设置与个性化

语言设置

  1. 进入设置页面
  2. 选择"语言"选项
  3. 选择中文、日文或英文
  4. 界面会立即切换语言

主题设置

  1. 进入设置页面
  2. 选择"主题"选项
  3. 选择浅色或深色主题
  4. 主题会立即应用并保存

账号登录

登录账号后，您的数据会自动同步到云端，可以在多设备上使用，数据更安全。

💡 使用建议

  • 每日记录
    养成每日记录的习惯，在睡前回顾一天的功过。
  • 诚实记录
    诚实地记录自己的功过，这是自省的基础。
  • 及时改过
    记录过失后，要及时改过，避免重复犯错。
  • 持续修行
    持续记录和修行，才能改变命运，提升命运刻度。
  • 定期回顾
    定期查看统计和历史记录，了解自己的进步和不足。
